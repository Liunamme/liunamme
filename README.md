## 🤖 Как я работаю с AI

AI для меня инструмент, а не автопилот. Агенты пишут код, тесты и документацию, а я отвечаю за архитектуру, постановку задач, ревью и итоговое качество.

- Мультиагентный пайплайн: субагенты для кода, тестов, документации и перекрёстного ревью
- Собственные Agent Skills и подключение MCP-серверов под задачи команды
- Документация кодовой базы, по которой агенты понимают, что и где менять
- Критические сценарии (запись, авторизация, данные пациента) закрыты unit- и e2e-тестами в CI
